# Find Skill

**把"帮我找个技能"变成一份能被别人复核的检索记录。**

`find-skill` 是一个六层可审计的技能发现与选型引擎。它不只是搜到几个名字，而是明确回答三件事：每一层跑没跑、每一条来源能不能点开、每一句能力判断有没有原文依据。

## 它解决什么问题

常见的技能发现工具会出现四类失真：

- **层数注水**：对外宣称"六层联合搜索"，实际只跑了内置、聚合市场两三层，ClawHub 与 GitHub 从未执行。
- **文档与实现脱节**：描述里承诺的能力，在正文里找不到对应章节；接口地址写错，被误判为"市场不存在"。
- **同源重复计数**：聚合市场对上游做了联邦索引，同一个技能被当成两个候选，热度被叠加。
- **推断冒充事实**：描述里出现 chart 就写成"支持图表"，没有标注这是推断还是正文明确说明。

`find-skill` 把这些都写成了硬约束：未执行的层必须显式声明，零命中必须如实报告，推断必须与事实分离。

## 核心能力

### 1. 六层执行清单，逐层可审计

| 层 | 覆盖对象 | 作用 |
| --- | --- | --- |
| L1 | 客户端官方内置 | 零安装成本的兜底能力 |
| L2 | 用户级与工作区级已装技能 | 已付费或已配置的能力优先复用 |
| L3 | SkillHub | 商业与中文技能主来源 |
| L4 | 虾评 | 中文场景命中率通常更高 |
| L5 | ClawHub | 生态最大、采用度最高的一批 |
| L6 | GitHub | 开源技能与可审计源码 |

每一层都记录状态、命中数与失败原因。状态只有四种：已执行、降级执行、零命中、未执行。

### 2. 先本地后远程

本地已命中的能力优先推荐，远程更热门不构成替换理由。本地两层用脚本扫描，不靠人工比对目录名。

### 3. 三级去重，避免镜像挤占

规范名归一 → 来源标识归一 → 描述指纹比对。专门处理"同一技能被不同账号改名重复上架"的情况。

### 4. 四维排序，拒绝单一热度榜

能力匹配 40%、可信证据 25%、采用度 20%、维护活跃 15%。采用度取对数压缩，防止头部技能垄断排序。六类情况强制降级并写明原因。

### 5. 默认不安装

只做推荐。安装需要用户逐条确认来源、安全报告、目标目录与是否覆盖同名技能。

## 与旧版 find-skills 的差异

| 对比项 | 旧版 find-skills | find-skill |
| --- | --- | --- |
| 层数表述 | 描述写六层 | 描述与正文一致，正文给出六层完整端点 |
| ClawHub | 描述提及但正文无章节、无端点 | 给出可用的检索路由，并标注易错的 404 路径 |
| 本地已安装 | 只列目录 | 脚本扫描 frontmatter，按名称去重取最高版本 |
| 多版本内置技能 | 未处理 | 同技能多版本合并，记录被遮蔽版本数 |
| 同源去重 | 无 | 三级去重，识别联邦索引关系 |
| 输出 | 候选列表 | 覆盖矩阵 + 候选表 + 缺口声明 |
| 未执行层 | 静默省略 | 显式声明，并说明因此可能漏掉什么 |
| 安装 | 支持一键安装 | 默认只推荐，安装需显式确认 |

## 安装

```bash
git clone https://github.com/GodAI-Master/GodSkill.git
cp -R GodSkill/find-skill ~/.workbuddy/skills/find-skill
```

Windows PowerShell：

```powershell
$target = Join-Path $env:USERPROFILE ".workbuddy\skills\find-skill"
New-Item -ItemType Directory -Path $target -Force | Out-Null
Copy-Item ".\find-skill\*" $target -Recurse -Force
```

请复制完整目录，不要只复制 `SKILL.md`，否则参考文件与脚本会丢失。

## 使用

```text
帮我找几个处理 Excel 并且能图表展示的技能，列出用途和来源，先不要安装。
```

```text

```

```text
我要做数据看板，把能实现这个交付物的技能都找一遍，包括我已经装了的。
```

## 输出长什么样

一份合格输出包含六段：结论先行、六层覆盖矩阵、关键词组、候选表、分档推荐、缺口声明。

覆盖矩阵示例：

| 层 | 状态 | 命中 | 说明 |
| --- | --- | --- | --- |
| L1 官方内置 | 已执行 | 3 | 含 1 个直接对口 |
| L2 本地已安装 | 已执行 | 0 | 逐个匹配，无专用能力 |
| L3 SkillHub | 已执行 | 9 | 过滤 3 条低分噪声 |
| L4 虾评 | 已执行 | 6 | 仅核验前三条详情 |
| L5 ClawHub | 已执行 | 8 | 含 2 条与 L3 重复，已合并 |
| L6 GitHub | 降级执行 | 4 | 无令牌，未做代码级搜索 |

分档推荐而不是单一排名：零成本首选、通用主力、场景专用、待实测。分档表达的是"什么情况下用它"，比排名更能支撑决策。

## 文件结构

```text
find-skill/
├── SKILL.md                          # 主入口：硬约束、六层顺序、流程、边界
├── README.md
├── _skillhub_meta.json
├── references/
│   ├── layer-endpoints.md            # 六层真实端点、字段与失败模式
│   ├── scoring-and-dedup.md          # 三级去重与四维评分
│   └── output-contract.md            # 覆盖矩阵与候选表模板、禁止表述
├── scripts/
│   └── scan_local_layers.py          # 零依赖扫描 L1/L2，去重与关键词匹配
└── evals/
    └── route-cases.json              # 正例、负例、近邻三类路由用例
```

## 本地扫描脚本

```bash
python3 find-skill/scripts/scan_local_layers.py \
  --keywords excel xlsx chart 图表 \
  --top 10 --json scan.json
```

脚本只覆盖本地两层。它读取每个 `SKILL.md` 的 frontmatter，按技能名去重并保留最高版本，输出 Markdown 表格，可另存 JSON。零依赖，仅用标准库。

## 验证与证据边界

- [路由用例](evals/route-cases.json) 定义的是**期望行为**，不是实测结果。静态校验只能证明用例结构合法，不能证明客户端会按此触发。
- `scripts/scan_local_layers.py` 只能证明本地目录结构与 frontmatter 可解析，不能证明远程四层实时可达。
- 远程层的所有数字都带观测时间，市场数据会变。同一技能在不同市场的下载量口径不同，不可跨市场排名。
- 本技能不承诺提升召回上限，只承诺把已执行的检索如实呈现，把未覆盖的部分明确标出。

## 设计与验证

```bash
python3 no-repeat-skill/scripts/validate_skill.py find-skill --strict
```
