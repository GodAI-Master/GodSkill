# First Principles Decision

在重要决策前，先分清“真正要达到的结果”和“当前想到的做法”。

`first-principles-decision` 是一个面向复杂决策的 Agent Skill。它不会直接默认用户提出的方案就是最优解，而是先检查目标、前提、信息差、替代路径和失败风险，再给出明确的执行建议。

## 适合场景

- 购买设备、软件、服务或订阅。
- 选择框架、语言、数据库或架构。
- 设计产品功能、交互和系统方案。
- 搭建自动化、团队协作和工程流程。
- 规划学习路线、旅行方案或长期工具。
- 比较商业策略、成本效益和风险。

改写、润色、翻译、格式转换、简单事实查询和明确的单步执行不需要启动完整决策审查。

## 核心流程

1. **目标重定义**：明确最终要获得的结果，区分目标与方法。
2. **隐藏假设检查**：找出未被验证的前提、路径依赖和思维定式。
3. **信息差扫描**：对会影响结论的新工具、新规则和最新信息进行核实。
4. **替代路径比较**：审查更简单、更稳定、效果更好或更适合长期发展的方案。
5. **反方审查**：分析最可能的失败点，寻找低复杂度方案和从零开始的设计。
6. **执行决策**：不只罗列选项，给出明确结论、理由和执行要点。
7. **对抗性复核**：交付前再次检查事实、逻辑、隐性成本和可执行性。

## 输出特点

- 先给出结论和推荐方案。
- 明确说明原方案应继续、调整还是放弃。
- 将风险和规避措施放在显眼位置。
- 再展示目标、假设、信息和替代方案的分析依据。
- 问题越重要，审查越深；不用同样的篇幅处理所有决策。

## 使用示例

```text
请使用 $first-principles-decision 分析：我们是否应该把现有系统拆成微服务？
```

```text
我准备购买一台新设备长期运行 AI Agent，请检查我的前提和更低成本的替代方案。
```

## 安装

```bash
git clone https://github.com/GodAI-Master/GodSkill.git
```

将完整的 `first-principles-decision/` 目录复制到目标 Agent 的 skills 目录。

## 目录内容

```text
first-principles-decision/
├── README.md             # 给人阅读的独立介绍
├── SKILL.md              # Agent 读取的核心指令
└── _skillhub_meta.json   # Skill 元数据
```
